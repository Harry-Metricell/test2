# Acceptance Criteria

- [ ] Starting from the V4 launcher, the signed-in user opens GIS, loads an available Surveyor layer, and the layer legend displays a `Display Settings` control.
- [ ] After opening `Display Settings`, the panel displays a `Show linked sites` control with a discernible current state.
- [ ] After changing `Show linked sites` to the opposite state, the control visibly displays the new state.
- [ ] After restoring `Show linked sites` to its original state, closing and reopening `Display Settings` shows the original state again.
