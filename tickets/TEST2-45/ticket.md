## Acceptance Criteria

1. Supported Surveyor layers can be selected from the GIS layer panel.
2. A user without access does not see an unavailable layer.
3. The Surveyor group appears beneath Tests and Measurements.
4. The eight GIS layer entries are Data Experience, Ping, Service, Building, Download, Upload, Site Testing, and Call.
5. Retired User, Browsing, and YouTube layers are absent.
6. Validation: For an authorised signed-in user, inspect the GIS layer browser and select available Surveyor entries. The permission-negative check requires a suitable restricted account; do not infer that behaviour from one authorised account. This is a GIS layer catalogue check, not a launcher module or Survey Analyser check.
