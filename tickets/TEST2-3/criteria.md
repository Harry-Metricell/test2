## Preconditions

- The tester is signed in and can open a Beacon that is not currently favourited.

## Criteria

- [ ] When the tester favourites the selected Beacon, the Beacon is shown in the Favourites list.
  - Starting state: The selected Beacon is not in the Favourites list.
  - Proof: Capture the Beacon's favourited state and its presence in the Favourites list.
- [ ] When the tester removes the selected Beacon from favourites, the Beacon is no longer shown in the Favourites list.
  - Starting state: The selected Beacon is present in the Favourites list.
  - Proof: Capture the updated unfavourited state and the Favourites list without the Beacon.
