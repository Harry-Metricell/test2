- [ ] Before selecting the MS Teams Call layer, the map shows no MS Teams Call test-result points.
- [ ] When the user selects the MS Teams Call layer and authorised matching results are available, each matching result is shown as a selectable map point.
- [ ] For a displayed MS Teams Call point with Poor Quality 0–0.99, its map colour is Green.
- [ ] For a displayed MS Teams Call point with Poor Quality 1–9.99, its map colour is Yellow.
- [ ] For a displayed MS Teams Call point with Poor Quality 10–24.99, its map colour is Amber.
- [ ] For a displayed MS Teams Call point with Poor Quality 25 or greater, its map colour is Red.
- [ ] When the user selects a map point and its details load successfully, the details dialog displays Test ID, Test Result, Connection Time, Call Duration, Poor Quality, MSISDN and Test Technologies.
- [ ] When the user selects a map point and its details load successfully, the details dialog displays signal and download charts and shows handover markers when available.
- [ ] When the user selects a map point and its details load successfully, the details dialog displays a detailed-sample table that omits label, latitude, longitude and handover-only columns.
- [ ] When detailed samples are displayed, sorting a supported column changes their displayed order to match the selected sort.
- [ ] When detailed samples are displayed, filtering a supported column limits the displayed samples to those matching the filter.
- [ ] When the user exports a selected test as CSV, the exported CSV contains data for that selected test.
- [ ] When a zero-duration result is selected, its details dialog does not display stale or misleading data.
- [ ] When details for a selected result fail to load, the dialog does not display stale or misleading data.
