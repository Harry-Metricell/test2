## Description

A user working in GIS changes the visible coverage layer, closes the layer panel, adjusts the map, and returns to the default view. The chosen coverage remains visible after the panel closes. Map navigation keeps its current position while the user changes tools. Returning to the default view restores the starting area while leaving the map controls available.
