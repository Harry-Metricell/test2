# Criteria

## GIS launch and map search

- Starting from the V4 launcher, open GIS. Verify that the GIS workspace loads with the map and available GIS controls visible.
- Use the GIS map search to search for a known site or location and select a result. Verify that the map moves to the selected result and identifies it as the active location.
- Select the visible map marker for the selected location. Verify that a details panel opens for that same location and displays identifying information.
- Close the details panel. Verify that the map remains at the selected location and the GIS controls remain usable.
