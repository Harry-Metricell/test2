# Acceptance Criteria

- [ ] After opening GIS and loading an available Surveyor layer, the layer legend displays a Display Settings control.
- [ ] Opening Display Settings displays a Show linked sites control with an identifiable checked or unchecked initial state.
- [ ] Changing Show linked sites to the opposite state visibly changes the control to that new checked or unchecked state.
- [ ] Restoring Show linked sites to its initial state, closing and reopening Display Settings, displays the same initial state.
